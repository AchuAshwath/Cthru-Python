## Why Cthru-Python?

<CardGrid stagger>
  <Card title="Variables Are Not Boxes" icon="warning">
    Every intro course tells you variables are containers holding values. In Python, variables are
    **labels (pointers)** pointing to objects in the heap. Understanding this unlocks mutability,
    aliasing, and closures.
  </Card>
  <Card title="Mechanical Empathy" icon="laptop">
    You don't need to write C to master Python, but understanding the **Call Stack, Private Heap,
    and bytecode execution loop** makes you write cleaner, faster, bug-free code naturally.
  </Card>
  <Card title="The Universal PyObject" icon="puzzle">
    Discover why an integer takes 28 bytes in Python, what `id()` and `sys.getrefcount()` actually
    measure, and how the Small Integer Cache works under the hood.
  </Card>
  <Card title="Curated from First Principles" icon="open-book">
    Inspired by seminal engineering talks, books like *Fluent Python* and *CPython Internals*, and
    actual source code from CPython's GitHub repository.
  </Card>
</CardGrid>
