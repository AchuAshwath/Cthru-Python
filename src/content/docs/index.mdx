## The Bug That Breaks Every Beginner

Ask someone who has been writing Python for six months what this does:

```python
a = [1, 2, 3]
b = a
b.append(4)

print(a)
```

Almost everyone who was taught that _"a variable is a box containing a value"_ guesses `[1, 2, 3]`.  
When the terminal prints `[1, 2, 3, 4]`, they memorize a rule: _"Lists are mutable, numbers are immutable."_

That isn't an explanation—it's a coping mechanism.

### What Actually Happened in RAM:

1. `[1, 2, 3]` is allocated at heap address `0x10f440`.
2. `a` is an 8-byte pointer holding the address `0x10f440`.
3. `b = a` copies the **address**, not the list. Now both `a` and `b` point to `0x10f440`.
4. `b.append(4)` modifies the memory block at `0x10f440`.
5. Printing `a` reads `0x10f440`. Of course it shows `4`—there was only ever **one list** in memory.
